# 2D Space Shooter Game Improvement

## Overview

This project is an improved version of a 2D space shooter game. The update focuses on improving the player experience through clearer menu navigation, better instructions, and a more challenging Level 3.

The main improvements include:

- A working Instructions page
- A clearer menu flow
- A new Level 3 scene
- More enemies in Level 3
- Updated Level 3 win condition
- New gameplay features such as Speed Boost and Black Hole Hazard
- Fixed Level 3 scene loading through the Level Select menu
